1. はじめに

本アプリは、スマートフォンまたはPCのブラウザから利用できる勤怠管理システムです。 利用には以下の2つの URL があります。

用途URL
スタッフ用（出退勤・申請・部署上長承認）https://l91005025-png.github.io/kanko-app/kintai-staff.html
管理者用（最終承認・集計・部署管理）https://l91005025-png.github.io/kanko-app/kintai.html
推奨ブラウザ: Chrome / Safari / Edge の最新版。
通信環境: インターネット接続が必要（社内Wi-Fi または モバイル回線）。

権限の3層構造

権限できること使うアプリ
スタッフ打刻・自分の勤怠閲覧・申請スタッフ用
部署上長上記＋自部署の有給を一次承認スタッフ用
管理者（総務）すべての操作・最終承認・部署設定・有給残数管理両方

2. アプリのインストール

本アプリは PWA（Progressive Web App）に対応しており、 スマホのホーム画面に追加することで通常のアプリのように起動できます。

iPhoneユーザー必読: プッシュ通知を受信するには 必ず「ホーム画面に追加」 が必要です。
Safariのタブで開いたままだと通知が届きません。

2.1 iPhone（Safari）の場合

1Safari でスタッフ用 URL を開く
2下部メニューの 共有ボタン（□に↑）をタップ
3メニューから 「ホーム画面に追加」 をタップ
4名前を確認して 「追加」
5ホーム画面に追加されたアイコン（家＆人のロゴ）から起動

2.2 Android（Chrome）の場合

1Chrome で URL を開く
2右上の ⋮（3点メニュー） をタップ
3「ホーム画面に追加」 または「アプリをインストール」を選択

2.3 PCの場合

ブックマークに登録するだけで使えます。Chrome / Edge ならアドレスバー右端の「インストール」アイコンからアプリ化することも可能。

10. 【部署上長】有給を一次承認する

あなたが部署上長に設定されている場合、「申請」タブの上部に「部署上長として承認」セクションが表示されます。
申請
部署上長として承認

自部署の有給を一次承認してください。承認後、総務へ進みます。

山田 太郎 / 有給
対象日: 2026-05-10
理由: 私用のため
▲ 部署上長承認セクション

承認の流れ

1申請が出るとプッシュ通知が届く
2通知をタップしてアプリを開く
3「申請」タブの上部に承認待ちが並ぶ
4内容を確認して「承認」または「却下」
5承認すると総務（管理者）へ自動で回る
あなた自身の有給申請は、自分で承認することはできず管理者が直接承認します。
却下した場合は、申請者本人にも自動でプッシュ通知が届きます。
却下理由は別途口頭やチャットで伝えてあげると親切です。

11.1 スタッフを追加する

1「スタッフ」タブを開く

最後の管理者は降格できません。 必ず2名以上の管理者を維持してください。

12. 【管理者】部署を設定する

各部署ごとに 勤務時間・休憩・所定労働時間・公休パターン を個別設定できます。スタッフは所属部署の設定に従って勤怠が計算されます。

12.1 部署を追加する

1「部署」タブを開く
2「部署追加 / 編集」フォームに記入:
  • 部署名（例: 営業部）
  • 始業時刻・終業時刻
  • 休憩（分）・所定労働時間（分）
  • 定休パターン（次節）
  • 固定休日（毎年同じ日付・任意）
3「保存」

12.2 部署を編集する

一覧の各部署で「編集」 → フォームに値が入る → 修正して「保存」。

12.3 部署を削除する

所属スタッフがいる場合は確認ダイアログが出て、削除すると全員「未所属」に戻ります。

13. 【管理者】公休パターンと月別調整

会社の公休が「毎週日曜・第1月曜・第3土曜」のように複雑なパターンの部署にも対応。さらに「今月だけこの日を休みにする」といった月別の例外も設定できます。

13.1 定休パターンの設定

部署編集画面で「定休パターン」セクション:

1「＋ パターン追加」をクリック
2左のドロップダウンで頻度を選ぶ:
  • 毎週 / 第1 / 第2 / 第3 / 第4 / 第5 / 最終
3右のドロップダウンで曜日を選ぶ
4必要な数だけ繰り返す（複数追加可）
5「保存」
例:
・毎週 日曜
・第1 月曜
・第3 土曜
→ これら全てが部署の公休になる

13.2 月別の調整（例外設定）

「今月の第1月曜は出勤、代わりに第2月曜を休みにする」等の臨時調整に使います。

1部署を編集中にすると下に「月別の公休調整」カードが現れる
2調整したい月を選択して「表示」
3カレンダーで日付セルをクリック:
  • 既定で休セル → クリックで「平日に取消」（黄色＋取消線）
  • 平日セル → クリックで「追加で休にする」（赤背景）
  • もう一度クリックで例外を解除し既定に戻る
4クリックごとに自動保存されます
月別調整はその月に対してだけ有効。翌月は再び元の定休パターンが適用されます。

15.1 二段階承認（有給）

有給申請は部署上長 → 管理者の順で承認されます。両方承認されて初めて「承認済み」になります。

段階表示あなた（管理者）の操作
1部署上長承認待ち原則として部署上長が処理。あなたが直接承認することも可能
2総務承認待ち「総務として承認」または「却下」をクリック
完了承認勤怠に反映、有給残数 -1日

15.2 単一承認（有給以外）

シフト休、半休、残業などは管理者の承認のみで完了します。

15.3 承認後の取消・編集・削除

操作動作
総務承認を取消有給残数を自動で戻し、申請中に戻す
編集日付・理由・種別を修正
削除申請を完全削除（誤申請の場合に使用）

16. 【管理者】有給残数を管理する

有給残数は承認時に自動で差し引かれるため、通常は手動操作不要。年初の付与や手動調整が必要な時だけ操作します。

16.1 全員に一括付与（年初など）

1「設定」タブの「有給休暇 残数管理」セクション
2付与日数を入力（例: 10）
3動作を選ぶ:
  • 残数に加算: 既存残数に追加（例: 5日残っていて 10付与 → 15日）
  • 残数を上書き: 全員を指定日数にリセット
4「全員に適用」 → 確認ダイアログ → OK

16.2 個別に修正する

1同セクションのスタッフ一覧で対象者を探す
2右の数値ボックスに新しい残数を入力
3「更新」
「上書き」モードは全員の残数を一律にリセットします。中途入社者の調整等は個別修正で行ってください。

17. 【管理者】カレンダーで全社の休暇を確認

「カレンダー」タブで全社の休暇予定を月単位で俯瞰できます。

  • 部署フィルタで特定の部署だけ表示
  • 「承認済のみ」/「承認＋申請中」を切替
  • 休暇種別ごとに色分け表示（有給=黄、シフト休=紫、残業=青、など）
使い時: シフト調整・人員配置の検討、申請承認前に他の人の予定を確認。

18. 【管理者】CSV出力する

18.1 月次勤怠 CSV

1「勤怠」タブで対象月を選択
2「📥 CSV出力」をクリック
3勤怠_年月.csv がダウンロード
CSV項目: 氏名・メール・日付・曜日・出勤・退勤・労働時間（分）・残業時間（分）・備考

18.2 申請履歴 CSV

1「申請」タブで絞り込み（ステータス・スタッフ）
2「📥 CSV出力」
3申請_年月日.csv がダウンロード

CSVは UTF-8 BOM 付きで出力されるため Excel でそのまま開けます（文字化けなし）。

19. 【管理者】背景画像を変更する

管理者アプリの背景に好きな画像（社のロゴ、好きなキャラクター等）を設定できます。
この設定は このブラウザにのみ保存 され、他のスタッフには影響しません。

手順

1「設定」タブの「背景画像」セクション
2画像ファイル（JPG/PNG/WebP、推奨2MB以下）を選択
または画像URLを入力して「URLを適用」
3カードの不透明度スライダーで透け具合を調整（背景が透けすぎると文字が読みにくいので90%前後推奨）
4不要になったら「背景を解除」

20. 【管理者】退職者を削除する

削除はワンクリックで実行されます。 取消できないため、本当に削除してよいか確認してから実行してください。

手順

1「スタッフ」タブで該当スタッフを探す
2右端の 「削除」 ボタンをクリック
3確認ダイアログで「OK」
4「削除しました（Authアカウント含む）」と表示されれば完了
この削除では:
  • Firebase Authentication のログインアカウントを削除（再ログイン不可に）
  • users ドキュメントを削除（社内データから消える）
過去の打刻・申請履歴は残ります（労務監査用）。完全削除したい場合はFirebase Consoleから手動で消してください。

21. よくある質問

Q1. パスワードを忘れたら？

管理者に連絡してください。Firebase Console からパスワードリセットメールを送信できます。

Q2. 打刻を間違えたら？

「申請」タブから「打刻修正」申請を出してください。急ぎは管理者に直接連絡。

Q3. 在宅勤務でも打刻できる？

はい、インターネット接続があればどこからでも可能です。

Q4. 通知が来ない

以下を確認:

  1. iPhone の場合「ホーム画面に追加」したアプリから起動しているか
  2. 「打刻」タブの通知許可カードで「✓ 通知が有効です」と出ているか
  3. ブラウザ設定で通知がブロックされていないか

Q5. 部署が変更になったら？

管理者がスタッフタブで「部署」を変更してください。即座に新部署の勤務時間・公休パターンが適用されます。

Q6. 部署上長が退職した場合は？

管理者が新しい上長を立てるまで、その部署の有給申請は管理者が直接承認します（自動的にエスカレーション）。

Q7. 半休を取ったら有給残数は？

承認時に -0.5日 として自動計算されます。

Q8. 有給残数を超えて有給申請すると？

申請時に確認ダイアログが出ます。原則は事前に管理者へ相談してください。

Q9. 公休の調整がスタッフから見えない

強制リロード（Cmd+Shift+R）でデータが最新化されます。

Q10. データのバックアップは？

Firebase が自動でバックアップしています。加えて、月次でCSVを出力して保管することを推奨します。

打刻ボタンが押せないすでに打刻済みの可能性。「勤怠一覧」で当日の状態を確認

通知が来ないQ4を参照。iPhoneは「ホーム画面に追加」が必須
画面が古いまま更新されないCmd+Shift+R（Mac）/Ctrl+Shift+R（Win）で強制再読み込み
部署上長承認セクションが表示されない管理者にあなたの「部署上長」フラグが立っているか確認してもらう
